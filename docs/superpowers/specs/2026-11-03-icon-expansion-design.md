# 图标扩展与动效设计

用户已确认：延续 24×24 线性 SVG 风格，新增 120 个不重复图标，覆盖数据分析、服装零售、库存物流、办公和系统操作；悬停、点击、持续播放三种触发模式，默认静止。保留 spin 与现有名称、命名组件、尺寸、颜色、插槽和无障碍行为。

采用原生 SVG + CSS，不引入依赖。相比引入另一套图标包，可保持现有描边和构建方式；相比仅复用 spin，增加 pulse/bounce/shake/draw 等适用不同语义的效果。新增 animation 与 animationTrigger；持续模式显式设置 animation 后生效，未设置效果始终静止。hover 同时响应容器 focus-within，click 监听图标及最近的可交互祖先，从而支持外层按钮键盘激活；一次动效结束清理状态。spin 优先于 animation，旋转由外壳承担，新增效果作用于 SVG，避免覆盖 rotate。

预览使用现有 Gallery 页面，支持搜索、动效/触发选择、点击选择和可复制用法。减少动态效果设置停止所有动效。通过渲染去重、交互单测、浏览器动画/减少动效/键盘验证、类型检查和完整构建验收。
