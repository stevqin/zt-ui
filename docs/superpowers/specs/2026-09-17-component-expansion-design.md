# Zt UI 组件补全方案（用户已确认）

## 盘点结论

现有 38 个组件文档入口，源码和文档路线图另列 29 项规划。对照 Element Plus 官方组件总览（https://element-plus.org/en-US/component/overview.html，2026-09-17 查询），本次建议交付 41 个新增组件/服务及 4 项扩展能力，共 45 项。子组件不单独计数；现有 Modal 对应 Dialog，VTableGrid 已承担虚拟表格，不重复造同义组件。

“全部”以本文清单和行为边界为验收范围，并不表示穷尽所有业务组件。富文本、图表、地图、流程编排、甘特图、文件管理器属于独立业务系统，不纳入通用组件库本轮交付。

## 方案选择

1. 推荐：完整实现下列 45 项，按依赖顺序分阶段验收。每项同时交付源码、测试、可运行示例和 API，阶段划分不削减总范围。
2. 仅完成既有路线图 29 项：范围更小，但会保留 Card、Loading、Notification 等常见缺口。
3. 直接包装 Element Plus：能较快增加数量，但会引入第二套依赖、主题和行为，无法保证现有尺寸、圆角、Form 和浮层体系的一致性，不推荐。

## 第一组：布局与展示基础（11 项）

| 项目 | 可验收的行为边界 |
| --- | --- |
| Layout | 页面容器及 Header/Aside/Main/Footer 子组件；方向推导、侧栏宽度、响应式示例；语义标签和插槽。 |
| Row | 24 栅格行，水平/垂直间距、换行、主轴和交叉轴对齐。 |
| Col | span/offset，xs/sm/md/lg/xl 断点，嵌套栅格；与 Row 共享间距上下文。 |
| Space | 水平/垂直排列、换行、对齐、数字/元组间距、分隔插槽；空节点不产生多余间距。 |
| Divider | 水平/垂直、虚线、文本位置、默认插槽。 |
| Card | 标题、extra、正文、footer 插槽；边框、阴影、内边距与加载状态。 |
| Splitter | 水平/垂直分栏、受控尺寸、最小/最大约束、收起恢复；指针和键盘调整。 |
| Typography | 标题、段落、语义修饰、复制成功/失败反馈；复用 Text，避免重复字号体系。 |
| Empty | 默认图形、自定义图形和说明、操作插槽、可访问文本。 |
| Skeleton | 加载切换、动画、行数和宽度；SkeletonItem 形状及内容插槽。 |
| Statistic | 数字精度、分组、前后缀、自定义格式；非有限值有明确后备，不以零冒充错误数据。 |

## 第二组：反馈与浮层（7 项）

| 项目 | 可验收的行为边界 |
| --- | --- |
| Alert | 状态、标题/正文、图标、关闭和关闭事件，适当的 alert/status 语义。 |
| Loading | 区域加载与全屏加载、文本和图标、锁定策略；声明式组件及可关闭的命令式实例。 |
| Message | success/info/warning/error、持续时间、手动关闭、多条堆叠和去重、closeAll；鼠标悬停暂停。 |
| Notification | 四角位置、标题和正文、操作内容、持续时间、关闭、多个实例排列。 |
| MessageBox | alert/confirm/prompt；Promise 结果区分确认、取消和关闭；异步提交、输入校验、焦点恢复。 |
| Tooltip | hover/focus、延迟、禁用、定位、箭头、aria-describedby；复用现有定位与浮层管理。 |
| Dropdown | click/hover 触发、分组/分隔/禁用/图标、command 事件、方向键/Enter/Escape、选择后关闭。 |

命令式反馈在 setup 中提供可继承当前 ConfigProvider 的使用入口；应用外调用使用显式配置或默认值。实例关闭和组件卸载均清理定时器、节点与事件。MessageBox 复用 Modal 的焦点和异步关闭机制。文本默认按文本渲染，不提供默认 HTML 注入路径。

## 第三组：复杂表单（10 项）

| 项目 | 可验收的行为边界 |
| --- | --- |
| Autocomplete | 文本 v-model、同步/异步建议、debounce、loading、清空、禁用；过期响应不覆盖新查询，完整键盘选择。 |
| InputTag | 字符串数组 v-model，Enter/分隔符提交、粘贴拆分、去重、数量限制、删除、只读/禁用及 IME 保护。 |
| Mention | 配置触发前缀、本地/异步建议、键盘选择、插入位置和选择事件；普通 textarea 文本值，不引入富文本依赖。 |
| Cascader | 字段映射、多级路径值、单选/多选、严格模式、搜索、禁用、懒加载及失败重试、清空。 |
| TreeSelect | 复用 Tree；单选/多选、父子联动策略、过滤、清空、禁用和懒加载；折叠标签。 |
| TimePicker | 自定义面板，HH:mm[:ss]、步长、禁用时间、单值/范围、清空；与日期组件一致的移动端交互。 |
| TimeSelect | start/end/step 生成时间选项，边界校验、禁用区间、搜索/清空；独立于系统时间选择器。 |
| ColorPicker | 自定义色盘、色相/透明度、HEX/RGB/HSL 文本、预设、确认/取消、非法值反馈。 |
| Rate | 最大分值、半星、清空、只读/禁用、自定义图标、文字与键盘评分。 |
| Transfer | 双栏受控目标 key 数组、搜索、禁用、全选/半选、自定义标签/页脚、移动方向事件。 |

所有录入组件接入 Form 的 size/disabled/校验触发机制。值类型、空值、事件时机和异步竞态处理写入各自 types.ts 注释。弹出面板不得使用浏览器原生 select/date/color UI。范围面板在移动端提供明确的开始/结束选择状态。

## 第四组：结构化数据（4 项）

| 项目 | 可验收的行为边界 |
| --- | --- |
| Table | 原生 DOM 表格，列定义/插槽、行 key、排序、选择/半选、展开行、固定表头/列、空态/加载；通过事件支持服务端模式。大量数据继续使用 VTableGrid。 |
| Tree | 稳定节点 key、展开/选择/勾选、父子联动/严格模式、禁用、过滤、异步加载/重试、节点插槽、方向键导航；供 TreeSelect 复用。 |
| Timeline | 时间、内容、状态、自定义节点、倒序、左右/交替布局和窄屏排版。 |
| Calendar | 月/周视图、月份切换、选择日期、范围边界、日期单元插槽、节假日标识；复用日期计算。 |

## 第五组：导航与媒体（9 项）

| 项目 | 可验收的行为边界 |
| --- | --- |
| Anchor | 指定滚动容器、偏移、平滑滚动、活动章节同步、嵌套链接；支持文档站 header 下独立滚动区域。 |
| Affix | 指定容器、上/下偏移、占位保持布局、状态事件；resize/滚动更新与卸载清理。 |
| Backtop | 指定滚动容器、出现阈值、平滑回顶、按钮插槽及可访问名称。 |
| PageHeader | 返回按钮和事件、面包屑、标题/说明/extra 插槽、窄屏换行。 |
| InfiniteScroll | 容器或页面触底触发、距离、首次加载、loading/disabled/finished；异步加载期间防重复，失败可重试。 |
| Carousel | 指示器/箭头、受控索引、循环、自动轮播、触摸滑动、键盘；悬停/聚焦/页面不可见暂停，尊重减少动画偏好。 |
| Tour | 受控步骤、目标元素/回调、遮罩、定位、上一步/下一步/完成/关闭；缺失目标回退为居中说明，支持目标滚动定位及焦点恢复。 |
| Watermark | 文本/图片、多行、旋转、密度、透明度、响应式更新；水印仅为视觉提示，不宣称防篡改或数据保护。 |
| QRCode | 文本、纠错等级、尺寸/边距/颜色、SVG/Canvas 与下载、空值/编码失败反馈；选用成熟编码库，测试独立解码结果。 |

## 第六组：复用已有组件的扩展（4 项）

| 项目 | 可验收的行为边界 |
| --- | --- |
| DatePickerPanel | 将现有日期面板作为公开内嵌入口；单值/范围、禁用日期、节假日、年份月份视图；选择器与面板共享状态规则。 |
| ColorPickerPanel | 公开 ColorPicker 的内嵌色盘入口；值、透明度和事件与弹出版本一致。 |
| Select 虚拟列表 | 在现有 Select 中增加 virtual/itemHeight/height 能力，保留搜索、多选、禁用和键盘行为；万级选项不全部挂载 DOM。 |
| Tree 虚拟列表 | 复用 Tree 节点模型，仅渲染展开可见行的窗口；过滤/展开/勾选/键盘焦点在虚拟窗口内保持一致。 |

这四项建立独立文档场景或页面，但不以重复实现来增加组件数量。日期范围继续支持双面板，日期和时间组件的 size/主题规则不能回退。

## 共用技术规则

- 沿用 Vue 3 + TypeScript + SCSS 和 Zt 前缀，按目录公开组件、类型和必要子组件。
- 沿用五档 size、六种 status、light/dark 与圆角变量。仅在有语义意义的组件上提供 status，不给布局/结构组件硬加状态色。
- 复用 ConfigProvider、Form 和 overlay；浮层通过 Teleport 后仍继承正确外观与层叠规则。
- 支持键盘、辅助技术名称、焦点恢复、触屏及 reduced-motion；组件挂载和卸载不得泄漏监听器/观察器/计时器。
- 不访问业务认证、不写死真实上传或数据接口；异步示例为可取消本地模拟，并明确接口适配方式。
- 现有 38 项保持兼容；任何已发布 API 的必要改变另作迁移说明。

## 文档和验收

每项交付包含：实现、公开类型、导出、关键行为测试、文档目录/路由、精确 API、真实运行示例。示例继续以同一 .vue 文件渲染并通过 ?raw 展示，代码不得省略状态/方法/数据/样式。基本/状态/尺寸/主题/插槽/事件/边界场景按能力适用性覆盖；表单新增项进入 Form 综合校验场景。

补齐命令式服务的 API 生成规则；API 文案逐项说明具体行为，不用通用模板掩盖语义。首页和导航数量从目录动态推导，移除写死 38 的断言和展示。路线图只有通过验收的项才能转为已实现。

每阶段执行库测试和构建、site 测试和构建；浏览器检查亮暗主题、五档尺寸、390px 窄屏、header 下独立滚动容器、浮层/焦点及复制源码。最终提交并推送 GitHub，检查 Pages 工作流和线上页面。阶段性提交用于可追溯和回归定位；总范围全部完成后才能报告本轮完成。

## 实施依赖顺序

1. 布局/展示基础与 Loading/Tooltip，先建立可复用底座。
2. Message/Notification/MessageBox/Dropdown，统一命令式反馈与浮层。
3. Tree → Cascader/TreeSelect/Transfer，Select/Tree 虚拟化；其余文本与评分组件。
4. 时间、颜色和日期面板；Form 联动及 Calendar/Table/Timeline。
5. 滚动导航、轮播、Tour、水印与二维码；完成全量文档、视觉与交互回归并发布。

本文件是整体边界和验收方案。各组实施前进一步明确类型签名及内部拆分，但不重复询问已经确认的通用规范和范围。
