# SKU 数量快速录入面板

PC 专用 ZtSkuInput，以颜色/SKC 为行、尺码为列录入 SKU 数量，复用 ZtSkuProduct。独立组件让单选 SKU 与多规格数量录入保持清晰的绑定契约。采用淡蓝主题色表头、固定颜色列、轻量网格、可选 SKC 缩略图及行列合计；窄容器内部滚动，不增加移动端交互模式。

product 为一个 SPU；v-model 为 SKU 代码到正整数数量的映射。空白和 0 移除该 SKU。数量上限 max 默认 999999；非法输入恢复当前值。不修改商品或绑定对象，受控赋值不触发 change。省略绑定时内部保存。数据变更后只展示当前有效 SKU，禁用规格保留已有数量但禁止编辑。

列默认按数据首次出现顺序合并，sizeOrder 可指定优先顺序；缺失组合显示横杠。Tab 使用原生焦点顺序，Enter/Shift+Enter 前后连续录入，上下箭头同列跳转并跳过不可编辑格。支持从 Excel 粘贴制表符/换行矩形数据，保留缺失或禁用格的坐标，非法片段忽略、空白清除，单次粘贴发出一次更新。

提供 showImage、showSummary、disabled、readonly、size；继承全局主题、尺寸、圆角、焦点策略。change 返回数量映射、正数量明细和总数量，明细保留原始商品/SKC/SKU。summary 插槽自定义汇总区，focus(sku?) 聚焦输入格。文档提供基础、约束、粘贴/键盘和与 SkuSelect 共享数据示例。
