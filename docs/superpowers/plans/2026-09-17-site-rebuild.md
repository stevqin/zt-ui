# Zt UI Site Rebuild Implementation Plan

**Goal:** Rebuild the documentation body and information architecture while preserving the current header.

1. Extend the documentation catalog with eight capability groups, stable component metadata, roadmap items, phases, and foundations.
2. Add failing catalog and route tests for the new information architecture.
3. Extract reusable sidebar, outline, and component-card presentation components.
4. Rebuild the application shell below the header with responsive desktop/mobile behavior.
5. Rebuild Home, Components, and Scenarios around the new component system.
6. Add Foundations and Roadmap pages and register them in search and routing.
7. Restyle demos, API tables, related links, dark mode, and size density using shared document tokens.
8. Run all library and site tests/builds, inspect the live site at representative viewports, commit, push, and verify GitHub Pages.
