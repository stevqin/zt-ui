# ZtSelect Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a production-ready Vue 3 Select component with single and multiple selection, local and remote search, scoped slots, keyboard accessibility, Form integration, complete tests, and copyable documentation examples.

**Architecture:** Keep option filtering and value normalization in pure helpers, and isolate debounced remote request state in a composable with stale-response protection. `ZtSelect.vue` owns interaction, ARIA state, Form integration, and a body-teleported fixed-position listbox; `select.scss` owns the existing zt-ui glass visual language and five-level sizing.

**Tech Stack:** Vue 3.5 Composition API, TypeScript 5.8, SCSS, Vitest 3, Vue Test Utils, Vite 6.

**Spec:** `docs/superpowers/specs/2026-09-15-select-design.md`

## Global Constraints

- Do not depend on Element Plus, VXE Form, or another UI component library.
- Option values are limited to `string | number | boolean`.
- Single mode emits one primitive value or `null`; multiple mode emits an array.
- Remote search uses a promise-returning `remoteMethod`, defaults to `300ms` debounce, and stale requests cannot overwrite current state.
- Support `mini`, `small`, `default`, `medium`, and `large`, including Form inheritance.
- Every visual site demo must expose complete copyable Vue + TypeScript SFC source through `DemoBlock`.

export interface ZtSelectProps {
  modelValue?: ZtSelectModelValue
  options?: ZtSelectOption[]
  multiple?: boolean
  filterable?: boolean
  remote?: boolean
  remoteMethod?: ZtSelectRemoteMethod

  disabled?: boolean
  size?: ZtComponentSize
  noDataText?: string
  remoteErrorText?: string
}

  blur: () => void
  open: () => void
  close: () => void

```ts
// options.ts
import type { ZtSelectModelValue, ZtSelectOption, ZtSelectValue } from './types'

export function filterSelectOptions(options: ZtSelectOption[], keyword: string) {
  const normalized = keyword.trim().toLocaleLowerCase()
  return normalized ? options.filter(option => option.label.toLocaleLowerCase().includes(normalized)) : options
}
export function singleValue(value: ZtSelectModelValue | undefined): ZtSelectValue | null {
  return Array.isArray(value) || value == null ? null : value
}
export function multipleValues(value: ZtSelectModelValue | undefined): ZtSelectValue[] {
  return Array.isArray(value) ? value : []
}
export function isOptionSelected(option: ZtSelectOption, values: ZtSelectValue[]) {
  return values.includes(option.value)
}
```

- [ ] **Step 3: Implement the remote composable**

```ts
import { ref, type Ref } from 'vue'
import type { ZtSelectOption, ZtSelectRemoteMethod } from './types'

export function useRemoteSearch(method: Ref<ZtSelectRemoteMethod | undefined>, debounce: Ref<number>) {
  const options = ref<ZtSelectOption[]>([])
  const loading = ref(false)
  const error = ref<unknown>()
  let timer: ReturnType<typeof setTimeout> | undefined
  let requestId = 0
  let disposed = false

  function search(keyword: string, onError?: (reason: unknown) => void) {
    if (timer !== undefined) clearTimeout(timer)
    const scheduledId = ++requestId
    error.value = undefined
    timer = setTimeout(async () => {
      timer = undefined
      if (disposed || !method.value) return
      loading.value = true
      try {
        const result = await method.value(keyword)
        if (!disposed && scheduledId === requestId) options.value = result
      } catch (reason) {
        if (!disposed && scheduledId === requestId) {
          error.value = reason
          options.value = []
          onError?.(reason)
        }
      } finally {
        if (!disposed && scheduledId === requestId) loading.value = false
      }
    }, Math.max(0, debounce.value))
  }

  function dispose() {
    disposed = true
    requestId += 1
    if (timer !== undefined) clearTimeout(timer)
    loading.value = false
  }

  return { options, loading, error, search, dispose }
}
```
