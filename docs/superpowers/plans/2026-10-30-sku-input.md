# SKU Input Implementation Plan


**Goal:** PC SKU 矩阵数量录入及文档、测试。
**Architecture:** 独立 ZtSkuInput 复用 SKU 专业数据类型，model.ts 负责矩阵和数量归一化，Vue 处理受控输入与键盘/粘贴，SCSS 使用现有 token。数量单元格组合自身 ZtInput。
**Tech Stack:** Vue 3、TypeScript、SCSS、Vitest、Playwright。
**Spec:** docs/superpowers/specs/2026-10-30-sku-input-design.md

## Global Constraints
- PC 端；复用 product_no/spu、skc、sku 和 snake_case 字段，无通用 code 适配。
- 保留现有组件及未提交修改，不发布、不提交。
- 所有文档、注释只说明产品行为，使用中立示例数据。

## Review Focus
- 受控父级拒绝更新时输入恢复，不能自行改变绑定数量。
- 缺失/禁用组合不得因粘贴错位或键盘跳转被写入。
- 空白、零、小数、负数、超大数量和外部非法值的归一化。
- 商品/尺码数据更新后的孤立键、不同尺码顺序和空数据。
- 全局尺寸、暗色、圆角、焦点策略及固定列滚动。
