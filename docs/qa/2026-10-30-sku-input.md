# PC SKU 数量矩阵验证

ZtSkuInput 以单 SPU 的 SKC 为行、size_code 为列，数量映射按 sku 保存，与 SkuSelect 共用专业商品数据结构。面板使用主题色表头、单层网格、SKC 缩略图、固定颜色列和表头，宽表只在组件内滚动。

验证范围包括：尺码合并及显式排序、缺失组合、禁用颜色与 SKU、只读、外部回显、受控拒绝更新、不可变更新、数量空白/零/非法输入/上限、当前商品筛选、空数据、行列汇总、原始业务对象、唯一输入 ID、输入法组合输入、FormItem 粘贴校验及禁用继承、连续键盘录入、Excel 矩形粘贴坐标和批量单次更新。

文档包含基础录入、禁用与上限、键盘与粘贴、尺寸与共享数据四组独立示例；公开 API 覆盖属性、事件、summary 插槽、数量结构和 focus 实例方法。文档导航在 SkuSelect 后增加 SkuInput，保持原有组件搜索优先顺序。

桌面浏览器检查 1440px 和 1024px 布局、五档全局尺寸、深浅主题、单元格无重复输入边框、固定颜色列及页面无横向溢出；保存浅色桌面与深色矩阵截图用于目视检查。

验证结果：组件库 1825 项测试、文档站 512 项测试和整站 75 项浏览器测试全部通过；两端类型检查及生产构建通过。组件契约审计覆盖 170 个公开组件，无未豁免问题；内容校验覆盖 87 页文档和 215 个独立示例。
