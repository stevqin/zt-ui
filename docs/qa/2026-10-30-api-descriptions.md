# API 说明完整性验证

文档范围为 84 个页面、105 个 UI 组件及 6 个反馈服务。覆盖 1114 个属性、283 个事件、174 个插槽、161 个实例成员及 379 个公开类型条目。

说明优先采用源代码 JSDoc；缺失时使用按组件和成员维护的说明。参数类型、必填标记和默认值继续从公开契约提取。未知成员不会自动获得通用占位句，文档检查将列出其页面、组件、分类和名称并阻止构建。

关键核对项：

- 徽标 offset 明确水平和垂直偏移，以及独立展示时不生效。
- Radio 与 RadioGroup 事件返回 label。
- Select 与 SelectBox 的实例 clear 受 clearable、已有选择及可编辑状态约束。
- VTableGrid 工具栏配置控制按钮集合，不改变模板中的排列顺序。
- Canvas 节点中尚未桥接的第三方声明属性，说明当前适配限制。
- Loading 的关闭 Promise 无返回值；Dialog 与 Drawer 的关闭结果包含 reason 和 value。

验证包括全部 API 缺失及占位检测、错误定位回归、源注释优先级、公开契约提取、全部独立示例挂载、类型检查和生产构建。浏览器在桌面及手机宽度检查 Badge、Select、VTableGrid 和扩展 Loading 的实际表格说明与页面宽度，并执行现有交互回归。

验证结果：434 项文档站测试与 30 项浏览器测试通过，类型检查和生产构建通过，全部 2111 个 API 条目均有说明且不含旧占位文案。
