# SkuInput 数量绑定与矩阵验证

数量绑定增加 valueType，默认 object，输出 { [sku]: quantity }；array 输出按矩阵行列顺序排列的 { sku, quantity }[]。对象或数组均按当前商品进行回显与数量校验。重复 SKU 采用最后一条记录，未知 SKU、非法数量和零数量不进入结果。切换输出模式不会自动清空数量或发出更新。change.values 跟随模式，change.entries 始终保留原始商品、SKC、SKU 与数量。公开类型通过泛型保持默认对象绑定及数组绑定的事件类型推断。

横向尺码列从全部 SKC 的 skus[].size_code 去重合并，按首次出现顺序排列，sizeOrder 可调整优先顺序。缺失组合保留占位，不挪动粘贴坐标。商品名称、商品代码和录入说明可通过 showProductInfo=false 隐藏，不影响数量、矩阵或汇总。

矩阵使用轻量表头和网格，突出已录数量，颜色列及合计列左右固定；常用尺码列在默认 PC 布局下尽量完整显示，宽表在组件内部滚动。保留全局尺寸、主题、圆角和焦点策略。主图示例内部网格增加明确的收缩约束，保持窄屏下的主图自动隐藏。

API 对 ZtSkuProduct、ZtSkuColor、ZtSkuOption 和 ZtSkuQuantityValue 展示直接从代码提取的字段表，包括类型、说明和必填标记。product_no 与 spu 至少提供一项，商品图片位于 SKC 层。全部五组 SkuInput 示例直接展开完整商品数据和图片辅助函数，不依赖隐藏的本地 data 文件。

验证覆盖：数组回显及重复记录、对象默认行为、受控拒绝更新、不可变更新、空数组清除、批量粘贴、禁用数量、数量上限、模式切换、商品信息显隐、左右固定列、实际字段表、完整展开代码、窄屏文档、明暗主题与尺寸，以及既有表单和键盘交互。

结果：1834 项组件测试、519 项文档测试、79 项浏览器测试通过。两端类型检查和生产构建通过；组件契约审计覆盖 170 个公开组件，无未豁免问题。内容校验覆盖 87 页文档、214 个独立示例。
