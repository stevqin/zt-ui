# API 类型展示与 SKU 尺寸验证

API 展示层在 Props/Options 表头保留完整参数类型名，不再在 Types 表重复展开相同的接口。按全部页面的公开组件识别对应类型，覆盖跨页面引用及 zt-alert 服务配置；独立业务结构、事件参数、插槽和实例类型继续展示。生成的 API 元数据和源代码类型定义保留。搜索对应参数类型时跳转至实际存在的 Props/Options 表，避免定位到被精简的类型行。

SkuSelect 的五档尺寸控制尺码按钮最小宽高、内边距、字号和按钮间距。短尺码按钮从 mini 的 48×28px 递增至 large 的 92×52px；长名称可扩展并换行。移除手机端固定高度覆盖，桌面和窄屏使用相同配置。未传 size 时继承 ConfigProvider，显式 size 优先。尺寸继承及显式 size 优先级通过自动化测试验证。

回归检查包括：重复接口和空 Types 分组隐藏、跨页面类型去重、服务 Options 去重、独立类型保留、元数据无修改、类型搜索定位，以及桌面 1440px 和手机 390px 下五档尺码按钮的实际尺寸、选择反馈、无页面横向溢出及局部尺寸覆盖。

验证结果：组件库 1811 项测试、文档站 504 项测试、整站 72 项浏览器测试全部通过。组件库和文档站类型检查、生产构建通过，组件契约审计覆盖 169 个公开组件，无未豁免问题。内容校验通过，共 86 页文档、211 个独立示例。
