# SkuInput 自适应布局与开发热更新验证

尺码列通过 colgroup 和固定表格布局均分剩余宽度；颜色列根据面板容器宽度在可读范围内变化，汇总列保持紧凑。表格仅在总列宽低于当前尺寸的可读下限时内部滚动。表头、数据行及尺码汇总行分别使用共享尺寸变量，mini、small、default、medium、large 同步控制行高、字号、图片、输入区和留白。长名称仍可自然撑高，避免裁切。

界面改为轻量横向分隔、柔和表头、非零数量底色和紧凑汇总，保留左右固定列、键盘焦点策略和明暗主题。没有数量时输入框保持空白，不设置数字占位。

当前 4185 开发服务曾在运行时沿用旧的导入类型缓存，showProductInfo 和 valueType 未进入组件 Props，属性被传入 attrs。文档站根目录在 site，库源码位于外部 src；类型导入在运行时擦除，默认监听未完整覆盖这些依赖。开发配置显式监听库 src 后，重新启动服务清理旧缓存，并用真实类型说明变更验证到 ZtSkuInput 的 HMR 更新。

直接验证当前 4185 页面：首个示例默认显示商品信息，开关可隐藏和恢复；运行时 Props 包含 showProductInfo、valueType，attrs 无误传属性；类型文件变更会热更新组件；数组模式输出正确，空输入框不存在 placeholder。

浏览器布局专项覆盖 1000px 和 720px 面板的等分列宽、颜色列缩放、正常 PC 宽度无过早横向滚动，以及五档表头、数据和汇总行的高度联动。另验证左右固定列、整型数量、对象/数组模式、字段文档和既有交互。

验证结果：1836 项组件测试、519 项文档测试及整站 81 项浏览器测试全部通过；两端类型检查和生产构建通过，170 个公开组件契约审计无未豁免问题。另在实际 4185 服务验证首个示例显隐、数组输出、无占位输入和类型文件热更新。
