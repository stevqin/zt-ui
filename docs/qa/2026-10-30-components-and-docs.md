# 组件与文档扩展验证

新增公开组件 ZtSkuSelect 与 ZtBlockquote，文档站共 86 页、208 个独立示例、107 个 UI 组件契约与 6 个反馈服务契约。

## 关键回归

- SKU 单选：SPU 切换、SKC 图片、尺码选择、颜色/尺码禁用、外部回显、动态失效、相同名称不同代码、显式 null 的严格受控语义及未传值的内部状态。
- 引用：原生 blockquote/cite、标题和来源插槽、嵌套、六种实际状态颜色与尺寸类隔离。
- Form：动态路径、增删字段、分组禁用、字段/整表校验、挂载初值重置、异步提交、服务端错误清理与失败重试。
- Table：本地及远程组合筛选、分页排序回首页、跨页选择、汇总、当前行鼠标/键盘交互、实测溢出 Tooltip；合并跨度受展开详情、固定分区和工具列限制，被截断覆盖的单元格恢复；样式回调可覆盖对齐，固定定位及宽度仍受保护。
- 搜索：ZtModal 遮罩关闭、快捷键、方向键/Enter、自动聚焦与关闭返回焦点。
- 布局：2560、1440、1199、1024、390px 下的网格宽度；窄屏不保留右栏轨道，全页不横向溢出；补测 1440×480 和 390×640 短视口及搜索弹窗。
- VTableGrid：真实 Canvas 坐标点击业务/操作链接，静态及按行参数，禁用/恢复、明暗主题；原生顶部汇总和应用汇总不触发业务行回调。

- 性能：无合并配置跳过跨度归一化，启用时按行/列预计算边界，原始索引使用保留首次出现语义的缓存；150 行 × 4 列及原始数据读取次数回归先确认失败后通过。

## 兼容约定

保留 Table 插槽 index 的显示索引语义，新增 rowIndex 提供原始数据索引。操作 handler 的第一参数继续为 row，新增第二参数提供 field/value/rowIndex/params/event。普通单元格链接使用 link 配置与 link-click 事件；render/slot 自定义内容优先。额外焦点环继续遵循全局 none/keyboard/all 策略。
