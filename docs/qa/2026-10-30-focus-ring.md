# 全局焦点环策略验证

`ZtConfigProvider.focusRing` 支持 `none`、`keyboard`、`all`。默认 `none` 隐藏额外外框和焦点光晕；`keyboard` 按键盘和指针事件切换显示；`all` 在控件聚焦时显示。隐藏视觉焦点环不移除焦点、Tab 顺序、校验、选中状态或正常投影。

嵌套 Provider 继承未指定项，允许局部覆盖。Vue 弹窗、下拉与图片预览携带所属配置到 Teleport 根。独立命令式反馈服务使用文档级策略：多个独立根 Provider 并存时，采用最先挂载且仍存在的根；最后一个配置卸载后恢复原文档样式。

共享键盘/指针监听与文档样式 watcher 独立于单个组件生命周期，并在最后一个使用者卸载时释放。键盘模式使用真实输入方式，不把文本框点击匹配 `:focus-visible` 当成键盘输入。额外光晕采用受控 CSS 变量，普通阴影和校验边框继续保留。

验证覆盖：

- 默认关闭、仅键盘、所有聚焦，以及运行时切换。
- 鼠标点击文本框、Tab 导航、指针重新接管、嵌套关闭。
- 默认状态和动态模式下的按钮、输入框、下拉选项及弹窗。
- 图片预览浮层的嵌套配置。
- 首个 Provider 卸载后其他根继续切换，最终恢复文档样式。
- zt-alert 独立消息框的默认关闭策略。
- 反馈服务容器嵌入 Vue 控件时，内部输入框不与外壳形成双环。
- 桌面 1440px、手机 390px 的专项浏览器验证。

文档站使用源码自带样式，取消重复加载已构建的旧组件 CSS。全局配置页面提供三种模式及浮层继承演示，中英文 README 与使用指南同步说明。

验证结果：组件库 1749 项测试、文档站 436 项测试、整站浏览器 35 项测试全部通过；组件库与文档站生产构建通过；公开组件契约审计无未豁免问题。
