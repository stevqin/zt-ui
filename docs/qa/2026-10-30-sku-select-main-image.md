# SkuSelect 主图自适应与显示控制

移除独立的尺寸与局部覆盖示例，保留组件尺寸 API 和对应自动化测试。增加 showMainImage 属性，默认 true；关闭时移除主图及其列，颜色和尺码区域占满可用宽度，不改变已选颜色、SKU 或业务事件。窄容器仍自动隐藏主图，颜色缩略图保持可用。

主图列采用随面板变化的比例布局，取消固定 3:4 区域。图片按原图比例展示，随可用宽度缩放，并通过最大高度与 contain 避免裁切或过高。新增主图使用示例，可切换横图/竖图、调整面板宽度和开关主图。

专项验证覆盖：默认显示、动态关闭与恢复、选中状态和事件数量保持不变、局部尺寸优先级、横竖图片比例、面板缩窄后的图片缩放、关闭后的规格区宽度，以及 320px 窄屏下主图隐藏、缩略图显示和无页面横向溢出。

验证结果：组件库 1827 项测试、文档站 512 项测试及整站 76 项浏览器测试全部通过；两端类型检查和生产构建通过。组件契约审计覆盖 170 个公开组件，无未豁免问题；内容校验覆盖 87 页文档、215 个独立示例。
