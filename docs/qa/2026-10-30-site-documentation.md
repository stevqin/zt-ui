## 使用说明

- 本地开发：在 `site/` 运行 `npm run dev`，默认端口 4185。
- 页面路由：`/#/guide/...` 与 `/#/components/...`；旧组件链接自动转向新地址。
- 示例的特殊依赖和显式局部配置在对应文档中说明。
- VTable 引擎保持异步加载，其生产 chunk 会触发 Vite 的体积提示。

## 文档交互与内容规范

- 页头使用ZtSelect 尺寸下拉框、0–24px 圆角 Slider 与太阳/月亮主题切换，移动端采用第二行工具栏；无数值输入。
- 侧栏分组使用独立标题背景与分隔；84 个导航项的中英文均保持单行，完整名称可通过标题查看。

- `/extensions` 提供 zt-alert 六类独立服务文档与13个交互示例；浮层内的更新、全屏、加载和关闭操作经过普通鼠标点击验证。
- 示例与说明统一使用虚构组织、产品和地址，并有内容扫描回归检查。
- 桌面与1024/768/390/320px布局、实际剪贴板一致性、导航和刷新持久化已用真实浏览器检查。
- Canvas 截图在布局稳定后使用视口截图，避免自动化元素截图临时将视口设为1×1而干扰图形引擎。
